# Smart Study Planner 📚

A simple and useful **Smart Study Planner built using Python** that helps students organize their daily study tasks, manage subjects, and plan their study time effectively.

## 🚀 Features

* Add study subjects and tasks
* Set study duration for each task
* Create a daily study plan
* View pending and completed tasks
* Track study progress
* Simple and beginner-friendly interface
* Helps students manage their time efficiently

## 🛠️ Technologies Used

* **Python**
* Python basic concepts
* Lists and dictionaries
* Functions
* Loops
* Conditional statements
* File handling

## 📌 How It Works

1. Enter the subjects you want to study.
2. Add tasks for each subject.
3. Enter the required study time.
4. The program creates a simple study plan.
5. Mark tasks as completed after studying.
6. Check your progress.

## 💻 How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run the Python file:

```bash
python study_planner.py
```

## 🎯 Purpose

The main purpose of this project is to help students organize their studies and develop better time-management habits. It is also designed as a beginner-level Python project to demonstrate practical use of Python programming concepts.
